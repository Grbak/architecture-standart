| Код | Требования                                                                                                                                                            | Комментарий |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- |
| F   | Функциональные (Functionality)                                                                                                                                        |             |
| F1  | Клиент может просматривать на сайте список доступных депозитов с актуальными ставками                                                                                 |             |
| F2  | Клиент может подать заявку на открытие депозита через сайт, оставив свой номер телефона и ФИО                                                                         |             |
| F3  | Менеджер бэк-офиса может просматривать через систему кол-центра заявки клиентов на депозит                                                                            |             |
| F4  | Клиент может просматривать в интернет-банке список доступных депозитов с актуальными ставками и персонализированные ставки лично для него                             |             |
| F5  | Клиент может подать заявку на окрытие депозита в интернет-банке, указав счёт и сумму депозита                                                                         |             |
| F6  | Операция создания заявки на открытие депозита через интернет-банк клиентом должна подтверждаться с помощью СМС-кода                                                   |             |
| F7  | Менеджер бэк-офиса может просматривать и обрабатывать созданные клиентами через интернет-банк заявки на открытие депозита                                             |             |
| F8  | Результат обработки созданной клиентом через интернет-банк заявки на открытие депозита должен приходить клиенту в СМС-уведомлении                                     |             |
| F9  | Менеджеры бэк-офиса должны иметь возможность менять в АБС информацию о ставках по депозитам                                                                           |             |
| F10 | Менеджеры фронт-офиса должны иметь возможность высчитывать итоговую ставку по депозиту в АБС                                                                          |             |
| U   | Удобство использования (Usability)                                                                                                                                    |             |
| U1  | Интерфейс нового функционала должен быть удобным и соответствовать дизайн-системе компании                                                                            |             |
| R   | Надёжность (Reliability)                                                                                                                                              |             |
| R1  | Сервисы должны быть доступны круглосуточно, включая выходные и праздничные дни                                                                                        |             |
| R2  | Доступность сервисов должна быть не менее 99,9%                                                                                                                       |             |
| R3  | Должна быть реализована фейловер-стратегия для переключения на резервный ЦОД в случае проблем с основным                                                              |             |
| P   | Производительность (Performance)                                                                                                                                      |             |
| P1  | Время отклика при выполнении операций в интернет-банке должно составлять не более 1 секунды                                                                           |             |
| P2  | Все сервисы должны подразумевать возможность горизонтального масштабирования в случае всплесков нагрузки                                                              |             |
| S   | Поддерживаемость (Supportability)                                                                                                                                     |             |
| S1  | Все сервисы должны подразумевать логирование событий                                                                                                                  |             |
| S2  | Должно быть настроено информирование о всплесках ошибок в логах                                                                                                       |             |
| +R  | + Ограничения (Restrictions)                                                                                                                                          |             |
| +R1 | Передаваемые с сайта данные должны быть зашифрованы в процессе передачи                                                                                               |             |
| +R2 | Передаваемые из интернет-банка данные должны быть зашифрованы в процессе передачи                                                                                     |             |
| +R3 | Функционал работы с СМС должен быть реализован в ядре системы, его разработка по возможности должна быть независима от подрядчика                                     |             |
| +R4 | Внедряемые в процессе доработок технологии должны быть совместимы с текущими                                                                                          |             |
| +R5 | В случае разработки сервисов с нуля необходимо выделять их в отдельные микросервисы                                                                                   |             |
| +R6 | В случае разработки сервисов с нуля стоит отдавать приоритет технологиям, либо уже используемым в банке, либо тем, в которых команда обладает достаточной экспертизой |             |

К арахитектурно значимым требования можно отнести требования категории R+.
